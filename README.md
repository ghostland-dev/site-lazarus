# Lazarus Site

Documentation website with getting-started guides, libraries and extensions.

## Features

- Next.js documentation pages
- Dark mode

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- shadcn/ui (Radix UI)

## Getting Started

```bash
git clone https://github.com/ghostland-dev/site-lazarus.git
cd site-lazarus
npm install
npm run dev
```

Other scripts:

- `npm run build`: next build
- `npm run lint`: eslint .
